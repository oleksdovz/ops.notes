### Було: Docker використовує стандартний каталог

Приклад мінімального `/etc/docker/daemon.json` на Linux Docker Engine:

```json
{}
```

### Стало: Docker отримав новий data-root

```json
{
  "data-root": "/mnt/container-data/docker"
}
```

Шлях прикладний. Додай ключ до чинного JSON, не замінюй весь файл цим прикладом. Ця правка лише змінює налаштування: не створює mount, не копіює дані та не переносить окреме сховище containerd.

Після підготовки mount, узгодженого копіювання зі зупиненими writers і збереження попередньої конфігурації перевір синтаксис:

```bash
sudo dockerd --validate --config-file=/etc/docker/daemon.json
```

### Якщо підтверджено окреме сховище containerd

Фрагмент верхнього рівня його фактичного TOML config; збережи version, plugins та решту параметрів саме своєї версії:

```toml
root = "/mnt/container-data/containerd"
state = "/run/containerd"
```

Це окрема зміна шляху, яка теж потребує узгодженого перенесення даних і простою. Не застосовуй її до невідомого instance containerd. Після запуску перевір фактичні шляхи й стан застосунків. Для повернення потрібні стара конфігурація та узгоджена копія; нові записи не можна просто залишити на новому диску й перемкнутися на старий.
