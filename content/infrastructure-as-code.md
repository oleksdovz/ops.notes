Цінність Infrastructure as Code — у можливості пояснити та відтворити бажаний стан системи. Конфігурація має бути зрозумілою людині, яка переглядатиме зміну.


## Зміна повинна читатися

Зберігай конфігурацію в системі контролю версій. Обмежуй кожну зміну однією метою. Перед застосуванням переглядай plan, особливо операції видалення та заміни ресурсів.


## Стан — частина системи

Terraform state може містити чутливі дані. Обирай сховище з належним контролем доступу та блокуванням, перевіряючи можливості конкретного backend. Не додавай state у публічний репозиторій.
