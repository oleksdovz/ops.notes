# The Burnt-Out DevOps

Статичний 18+ DevOps-журнал у roast-стилі з українським сленгом і лайкою. Технічні факти, команди й перевірки лишаються точними; зовнішніх шрифтів і залежностей для збірки немає.

Маркування 18+ попереджає про нецензурну лексику; механізму перевірки віку немає.

## Приклади конфігурацій

`examples/<slug>.md` — необов’язкові фрагменти до/після, фікс і перевірка. Збірка додає їх у практичний блок відповідної статті. Часткові маніфести мають бути позначені як часткові.

## Практичні блоки

`practical/<slug>.md` містить команди, інтерпретацію результатів і межі застосування. Для кожної статті потрібен однойменний practical-файл. Підтримуються також заголовки `###`. Збірка додає блок після розбору й посилання на нього у зміст.


## Оновлення статей
Редагуй Markdown у `content/`. Кожна стаття — окремий файл:

```md
---
title: Назва статті
category: Linux
summary: Короткий опис
order: 7
excuse: Типове виправдання
verdict: Короткий технічний висновок
consequence: Можливий наслідок
selfroast: Самоіронічна репліка редакційного персонажа
---

Перший абзац.

## Заголовок розділу

Текст із `командою` або [посиланням](https://example.com).
```

Підтримуються абзаци, заголовки `##`, inline code, блоки коду та HTTP/HTTPS-посилання. HTML не виконується. Назва файлу визначає URL; після публікації не змінюй її без налаштування перенаправлень.

Збірка: `node scripts/build.mjs`.

Файли в `dist/articles/`, `dist/index.html` та `dist/about.html` генеруються; редагуй першоджерела. Оформлення: `dist/style.css`. Пошук: `dist/app.js`.

## Публікація

Збірка створює локальні файли. Чинний deploy — ручний Gitea Actions workflow `.gitea/workflows/deploy.yml`: він збирає `dist/` і публікує сайт на приватній LAN-адресі `192.168.0.50:81` через обмежений SSH-доступ. `.openai/hosting.json` зберігає наявну Sites-прив’язку; не змінюй `project_id`.

### Готовність до Cloudflare Pages

Чинний деплой — через ручний Gitea Actions workflow; Cloudflare Pages поки лише погоджений майбутній напрям. Репозиторій підготовлений для нього, якщо напрям підтвердять:

- Root repo: `/`
- Build command: `node scripts/build.mjs` (або `npm run build`)
- Output directory: `dist`
- Node.js: зафіксовано у `.node-version` і `package.json` → `engines.node` (22.16.0, LTS за замовчуванням для build image Cloudflare Pages)

Збірка також генерує `dist/404.html` (Cloudflare Pages підбирає його автоматично для будь-якого невідомого шляху) та `dist/_redirects` (301 для перейменованих slug, формат Cloudflare/Netlify; старі `dist/articles/<old-slug>.html` лишаються як portable meta-refresh fallback для інших хостингів). Внутрішні посилання сайту завжди з явним `.html` або кореневим `/`; extensionless-доступ (`/articles/slug` без `.html`) не підтримується і не потрібен для навігації сайтом.

Підключення Cloudflare-проєкту, DNS і приватність — поза цим репозиторієм; виконується лише за явним дорученням.
