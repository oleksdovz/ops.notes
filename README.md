# ops.notes

Статичний журнал DevOps-фейлів у roast-стилі без матюків. Без зовнішніх шрифтів і залежностей для збірки.

## Приклади конфігурацій

`examples/<slug>.md` — необов’язкові фрагменти до/після, фікс і перевірка. Збірка додає їх у практичний блок відповідної статті. Часткові маніфести мають бути позначені як часткові.

## Практичні блоки

`practical/<slug>.md` містить команди, інтерпретацію результатів і межі застосування. Для кожної статті потрібен однойменний practical-файл. Підтримуються також заголовки `###`. Збірка додає блок після розбору й посилання на нього у зміст.


## Оновлення статей
Редагуй Markdown у `content/`. Кожна стаття — окремий файл:

```md
---
title: Назва статті
category: Linux
summary: Короткий опис
order: 7
excuse: Типове виправдання
verdict: Короткий технічний висновок
consequence: Можливий наслідок
selfroast: Самоіронічна репліка редакційного персонажа
---

Перший абзац.

## Заголовок розділу

Текст із `командою` або [посиланням](https://example.com).
```

Підтримуються абзаци, заголовки `##`, inline code, блоки коду та HTTP/HTTPS-посилання. HTML не виконується. Назва файлу визначає URL; після публікації не змінюй її без налаштування перенаправлень.

Збірка: `node scripts/build.mjs`.

Файли в `dist/articles/`, `dist/index.html` та `dist/about.html` генеруються; редагуй першоджерела. Оформлення: `dist/style.css`. Пошук: `dist/app.js`.

## Публікація

Збірка створює локальні файли. Для Sites потрібні синхронізація Git через Sites workflow, пакування та deploy. Автоматичний CI/CD у цьому проєкті не налаштований. `.openai/hosting.json` зберігає прив’язку до чинного сайту. Не змінюй project_id.
